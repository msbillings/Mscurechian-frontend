2. INPUT FIELD RESTRICTIONS
================================================================================

PATIENT NAME:
-------------
✓ Regex: /^[a-zA-Z\s]*$/
✓ Blocks: numbers, special characters
✓ Allows: letters (a-z, A-Z), spaces

PATIENT AGE:
------------
✓ Regex: /^[\d\sa-zA-Z]*$/
✓ Allows: numbers, spaces, letters
✓ Validates: 1-150 for numbers, 1-24 for months
✓ Examples: "25", "3 months", "6 MONTHS"

PATIENT MOBILE:
---------------
✓ Regex: /^\d{0,10}$/
✓ Exactly 10 digits
✓ Blocks: letters, special characters

EMERGENCY TYPE:
---------------
✓ Regex: /^[a-zA-Z\s,.-]*$/
✓ Allows: letters, spaces, comma, period, hyphen
✓ Blocks: numbers, other special characters

ETA (MINUTES):
--------------
✓ Type: text with numeric validation
✓ Regex: /^\d+$/
✓ Blocks: negative values, decimals, letters
✓ Max: 999 (3 digits)

VITALS - BLOOD PRESSURE:
------------------------
✓ Format: 120/80
✓ Regex: /^[0-9\/]*$/
✓ Max value per number: 150
✓ Auto-caps values > 150 to 150
✓ Example: "180/90" → "150/90"

VITALS - HEART RATE:
--------------------
✓ Range: 1-150 bpm
✓ Type: number input
✓ Blocks: decimals, negative values, values > 150
✓ Placeholder: "72 (max 150)"

VITALS - TEMPERATURE (°F):
--------------------------
✓ Type: text with decimal validation
✓ Regex: /^-?\d*\.?\d*$/
✓ Allows: positive AND negative values
✓ Allows: decimals (e.g., 98.6, -12.4)
✓ Blocks: letters, special characters (except . and -)
✓ Placeholder: "98.6 or -12.4"

VITALS - OXYGEN LEVEL (%):
--------------------------
✓ Range: 1-100%
✓ Type: number input
✓ Blocks: decimals, negative values, values > 100
✓ Placeholder: "98 (max 100)"

================================================================================
4. API REQUEST OPTIMIZATION
================================================================================

PROBLEM: Excessive polling causing 720 requests/hour

CHANGES MADE:
-------------

File: lib/hooks/emergency/useMyRequests.ts

BEFORE:
-------
refetchInterval: 5000,          // Polls every 5 seconds
refetchOnMount: true,            // Refetch on mount
refetchOnWindowFocus: true,      // Refetch on focus
refetchOnReconnect: true,        // Refetch on reconnect

Result: 12 requests/minute = 720 requests/hour

AFTER:
------
refetchInterval: false,          // NO polling
refetchOnMount: 'always',        // Only on mount
refetchOnWindowFocus: false,     // Don't refetch on focus
refetchOnReconnect: true,        // Keep reconnect (important)

Result: 1-2 requests/hour (only on mount/reconnect)

SAVINGS:
--------
✓ 99% reduction in API requests
✓ 720 → 1-2 requests/hour
✓ Reduced server load
✓ Better battery life on mobile
✓ Lower bandwidth usage
